# Technology Stack

## Programming Languages
- TypeScript 4.9.5 — All game logic, components, hooks, types
- TSX — React component files
- CSS — Styling (game.css)

## Frameworks
- React 18.2.0 — UI framework
- react-dom 18.2.0 — Browser renderer

## Build Tools
- react-scripts 5.0.1 — Webpack + Babel + ESLint bundled toolchain
- TypeScript compiler (tsc) — Type checking

## Runtime APIs
- requestAnimationFrame — Game loop (60fps)
- HTML5 Canvas 2D API — Game rendering
- KeyboardEvent API — Player input

## Infrastructure
- GitHub Actions — CI/CD pipeline
- Render — Static site hosting (CDN)

## Testing Tools
- Jest (via react-scripts) — Test runner (configured, no tests written)

## Node / npm
- Node 20.x — Runtime
- npm 9+ — Package manager
